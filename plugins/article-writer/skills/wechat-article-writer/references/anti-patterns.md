# 反模式:这些写法一律规避

公众号生态里有大量「流量套路」,它们能涨粉但会毁掉内容调性。这个 skill 的目标是写**有质感的科技文章**,所以下面列的写法,**无论看起来多有"标题党流量"**,一律不要用。

## 烂俗开头 ❌

| 反模式 | 为什么不写 |
|---|---|
| 「大家好,我是 XX」 | 主持人腔。读者订阅你时就知道你是谁,不需要每次打招呼。 |
| 「话不多说,直接开始」 | 既然话不多说,那就开始啊。这句话本身就是「话很多」。 |
| 「让我们一起来看看……」 | 把读者当小学生。 |
| 「在 AI 高速发展的今天」 | 空气句。所有这类时代背景式开头都是。 |
| 「相信很多朋友/家人/小伙伴」 | 流量号腔。「家人们」更不能写。 |
| 「不知道大家有没有这样的经历」 | 套路开头三巨头之一,出现一次扣一星。 |
| 「最近,XX 又火了」 | 80% 公众号都这么开头。看一眼就划走。 |
| 「我们都知道……」 | 假定共识,而且后面跟着的多半是常识。 |
| 「今天给大家分享……」| 「分享」是公众号词典里最被滥用的词。 |

## 烂俗结尾 ❌

| 反模式 | 为什么不写 |
|---|---|
| 「以上就是今天的分享」 | 直播间话术。读者知道文章结束了,不需要你宣布。 |
| 「我们下期再见」 | 视频结尾词,文章不需要。 |
| 「让我们一起期待……的未来」 | 「让我们一起」+「期待未来」=纯纯的废话乘以废话。 |
| 「未来可期」「拭目以待」 | 词典级垃圾词。一出现就显得作者懒。 |
| 「关于这件事,你怎么看?」 | 套路引导互动。如果文章本身没有真问题,这句话救不了。 |
| 「点赞、关注、转发」 | 除非用户明确要求商业转化,这种话一律不要。 |

## 烂俗中段 ❌

### "凡尔赛"式自我感动
> 「说实话,我也是熬了很多个夜,看了很多论文,才把这件事讲明白的。」

读者不关心你熬了多少夜。读者关心你讲了什么。

### 过度堆 emoji
> 「今天我们来聊聊 🔥 大模型 🚀 的最新进展 ✨,这真的太令人激动了 🎉🎉🎉!」

科技类公众号 emoji 适当用一两个表达情绪可以,通篇插花就 LOW 了。

### 「家人们」「绝绝子」「YYDS」「破防了」等流量词
科技类公众号读者审美偏严肃,这些词会瞬间让读者怀疑你的专业度。**严格禁用**。

### 「我有一个朋友,他……」的虚构小故事
读者一眼看穿是编的。如果素材里没有真实故事,不要硬编。

### 罗列十几个要点不分层
> 「Claude 4.7 的 10 大特性:1. 上下文长 2. 推理强 3. 速度快 4. 价格低 5. ……」

枯燥。不如挑 3 个最有反差的特性,每个展开讲一个具体场景。**少而深 > 多而浅**。

### 抽象形容词代替具体描述
> 「Claude 4.7 在编程能力上实现了重大突破。」

「重大突破」是什么?写出具体数字、具体场景、具体对比。**永远问自己:能不能用一个画面替换这个形容词?**

## 标题反模式 ❌

虽然这个 skill 没明确要求生成标题,但如果生成,以下标题套路一律不写:

- 「震惊!OpenAI 居然……」(震惊体)
- 「太可怕了!这个 AI ……」(惊悚体)
- 「不看后悔!史上最强 AI ……」(网赚体)
- 「一文读懂 XX」(虽然不算反模式,但已经被用烂)
- 「我用 XX 做了一件事,结果让我震惊了」(故弄玄虚体)

**好标题的特征**:具体、有信息量、有一点反差、不依赖夸张的形容词。例子:
- ✅ 「Anthropic 把 API 降价 80%,这是一个会改变行业格局的决定」
- ✅ 「我用 Claude 4.7 review 了 8 万行代码,发现了一件意外的事」
- ✅ 「Cursor 估值 99 亿,但赢的不是 AI」

## 结构反模式 ❌

### 「引言 → 背景 → 现状 → 分析 → 总结」的论文结构
这是学术论文模板,公众号读者读不下去。公众号应该:
**钩子开头 → 几个有节奏的故事/论点 → 锐利收束**。

### 通篇 H2 标题,每段不超过两行
看起来像 PPT,不像文章。**段落和小标题应该交错出现**,有的小节段落多一些(讲透一个点),有的小节短一些(节奏调剂)。

### 写到一半开始说"接下来我们将探讨……"
散文不需要导览。直接进入下一段,读者自然会跟着。

## 用词反模式 ❌

科技文章的"职业病"是堆术语。下面这些词如果出现,优先替换:

| 烂俗词 | 替换思路 |
|---|---|
| 「赋能」 | 几乎所有"赋能 X"都可以改成"让 X 能做 Y"。 |
| 「闭环」「抓手」「打法」「沉淀」 | 互联网黑话。能不写就不写。 |
| 「颠覆」 | 用滥了。除非真的颠覆,否则用具体动词(取代、改写、绕开)。 |
| 「赛道」 | 滥用程度仅次于"赋能"。 |
| 「生态」 | 在合理场景下可以保留(如"开源生态"),但不要每句都是"打造 XX 生态"。 |
| 「布局」 | 除非真的有"地盘划分"的含义,不然就是滥用。 |
| 「降维打击」 | 几乎所有"降维打击"都是夸大。 |

## 内容反模式 ❌

### 编造细节
**这是最严重的反模式。** 讲故事可以,但不能编造时间、人物、引用、数据。如果素材里没有,就用"据公开信息"、"业内人士透露"等模糊表达,或者干脆不写这个细节。

### 没有素材支撑的"业内人士"
「据业内人士分析……」如果你没有真实信源,这句话就是编。读者会感受到,即使他/她说不出来。

### 把"我猜"写成"我知道"
对未知的事情应该用「我推测」、「可能」、「看起来像」,而不是「事实上」、「显然」、「毫无疑问」。读者反感装。

---

## 总结一下反模式的核心

所有上面的反模式,本质上有三种问题:

1. **没信息量**——读了等于没读
2. **不真诚**——读者能感觉到你在演
3. **不个性化**——和市面上一千个公众号长得一样

写之前问自己:**这一段,读者会不会觉得"我读到的是只有这个作者会写出来的东西"**?如果不会,删掉重写。
