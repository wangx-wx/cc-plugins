# 一段对话 + 一些观察(关于 Cursor 这家公司)

(这是我和做 AI 投资的朋友 老 K 在咖啡馆聊的录音整理。本来准备写一篇,但一直没动笔)

---

我:你怎么看 Cursor 现在估值 99 亿这件事?

老 K:这个估值很有意思。你知道吗,Cursor 这家公司一共也就 30 个人,年化收入大概 3 亿美金。按照传统估值,这是个 30 亿美金的公司,顶天 40 亿。现在 99 亿,溢价的 60 亿,是在估什么?

我:估未来?

老 K:对,但你得问:是哪一种未来。我个人觉得,99 亿在估的是「Cursor 成为 AI 时代的 IDE 操作系统」这件事——就像 90 年代的 Windows、移动时代的 iOS。如果它真的成了,99 亿便宜。但如果只是一个工具,99 亿贵。

我:你觉得它能成吗?

老 K:不一定。你看它的护城河——它本质上调的是 OpenAI 和 Anthropic 的模型,模型本身是别人的。Cursor 唯一的护城河是「产品形态」和「用户习惯」。这就像当年的 Twitter——技术上没什么了不起,但抢到了「短文本社交」的心智位置。

我:Anthropic 自己出 Claude Code 算威胁吗?

老 K:算大威胁。Anthropic 既有模型,又开始做 IDE,这是从下往上打 Cursor。但 Cursor 跑得快,而且它现在已经积累了 50 万付费用户——这是 Anthropic 短期追不上的。

我:VS Code 怎么不入场?微软不是有 Copilot 吗?

老 K:这个事很微妙。VS Code 母公司是微软,微软投资了 OpenAI,但同时 GitHub 的 Copilot 团队和 OpenAI 也有合作。你看 Copilot 现在的处境——它没有 Cursor 那种「整个 IDE 重新设计」的勇气,因为 VS Code 不能为了 AI 把自己重做一遍。它只能在现有 IDE 上贴 AI——而 Cursor 直接 fork 了 VS Code 重做了一遍。

我:所以 Cursor 赌的是什么?

老 K:它赌的是:**AI Coding 是一个全新形态的产品,需要从交互层重新设计**。它赌微软放不下 VS Code 的历史包袱,所以微软追不上来。它赌 Anthropic 做不出比它更好的产品(虽然 Anthropic 模型强,但产品能力不一定强)。它赌 Cursor 在用户习惯固化之前——大概 18-24 个月内——拿到足够大的份额。

我:那如果赌输了呢?

老 K:99 亿就是个大笑话。可能 1 年后大家会说「记得有家公司叫 Cursor 吗」。

---

## 一些数据点(从公开资料整理)

- Cursor 团队人数:约 30(2025 年底)
- ARR:约 3 亿美金(2025 年底估计)
- 估值:99 亿美金(2025 年 10 月最新一轮)
- 付费用户:50 万+
- Anthropic Claude Code 用户:约 20 万(增速比 Cursor 更快)
- GitHub Copilot:1500 万+ 注册,300 万+ 付费(但很多来自企业捆绑销售)
- 主要投资方:Andreessen Horowitz、Thrive Capital、Index Ventures

## 我个人的判断

我觉得 99 亿这个估值,反映的不是 Cursor 这家公司本身有多值钱,而是**投资人对「下一代开发者工具的入口」这个位置的争夺已经白热化**。这个位置在 Windows 时代是 Visual Studio,移动时代是 Xcode,云时代是 VS Code——AI 时代是谁,还没尘埃落定。Cursor 是第一个抢到 pole position 的,但赛道才刚开始。
